## Q2

### Question

Take base hue `h = 0.55`. Build and display three colour palettes as horizontal
swatch rows in a 3×1 subplot grid:

1. Complementary (2 swatches)
2. Triadic (3 swatches)
3. Analogous (3 swatches, ±1/12 from h)

Use `skimage.color.hsv2rgb` and saturation/value of `(0.65, 0.9)`. Wrap hues
into `[0, 1]` with `np.mod`.

### Answer  (156s, 1294 completion tokens, 8.3 tok/s)

Assumptions:
- The figure will be a 3x1 subplot grid.
- Each subplot will display one color palette as a row of horizontal swatches.
- The base hue $h$ is $0.55$.
- Saturation is $0.65$ and Value is $0.9$ for all colors.

```python
import numpy as np
import matplotlib.pyplot as plt
from skimage import color

# Base parameters
h = 0.55
S = 0.65
V = 0.9

# 1. Complementary Palette (2 swatches)
hues_comp = np.mod([h, h + 0.5], 1.0)
cols_comp = [color.hsv2rgb([hh, S, V]) for hh in hues_comp]

# 2. Triadic Palette (3 swatches)
hues_tri = np.mod([h, h + 1/3, h + 2/3], 1.0)
cols_tri = [color.hsv2rgb([hh, S, V]) for hh in hues_tri]

# 3. Analogous Palette (3 swatches)
hues_ana = np.mod([h, h + 1/12, h - 1/12], 1.0)
cols_ana = [color.hsv2rgb([hh, S, V]) for hh in hues_ana]

# Setup the 3x1 subplot grid
fig, axes = plt.subplots(3, 1, figsize=(8, 4 * 1.5))
plt.suptitle(f"Color Palettes based on Base Hue h={h}", fontsize=14)

# Helper function to plot swatches
def plot_swatches(ax, colors, title):
    ax.set_title(title)
    for i, c in enumerate(colors):
        # Create a rectangle patch for the swatch
        rect = plt.Rectangle((i, 0), 1, 1, color=c)
        ax.add_patch(rect)
    # Set limits and remove axes for a clean swatch display
    ax.set_xlim(0, len(colors))
    ax.set_ylim(0, 1)
    ax.axis('off')

# Plotting the palettes
plot_swatches(axes[0], cols_comp, "1. Complementary Palette (2 swatches)")
plot_swatches(axes[1], cols_tri, "2. Triadic Palette (3 swatches)")
plot_swatches(axes[2], cols_ana, "3. Analogous Palette (3 swatches)")

plt.tight_layout(rect=[0, 0.03, 1, 0.95]) # Adjust layout for suptitle
plt.show()
```

Notes:
The `np.mod` function is crucial here to ensure that hues exceeding 1.0 or falling below 0.0 wrap correctly back into the [0, 1] range, which is required by `skimage.color.hsv2rgb`.
The swatches are plotted using `plt.Rectangle` objects added directly to the axes, ensuring they are displayed as horizontal rows.

## Q5

### Question

For the `fare` column of the Titanic dataset, compute Q1, Q3 and the IQR, derive
the lower and upper bounds using the 1.5 x IQR rule, and report how many values
fall outside them. Then cap the outliers instead of removing them, storing the
result in a new column, and draw side-by-side box plots of the fare before and
after capping. Print the maximum fare before and after.

### Answer  (182s, 1088 completion tokens, 6.0 tok/s)

Assumptions:
- The dataset used is the Titanic dataset, loaded via `sns.load_dataset('titanic')`.
- The target column for analysis is 'fare'.
- The outlier detection method is the 1.5 * IQR rule.
- The outlier handling method is capping (Winsorizing).

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# --- Step 1: Load the dataset ---
try:
    df = sns.load_dataset('titanic')
except Exception:
    df = pd.read_csv('titanic.csv')

print("--- Initial Data Profile ---")
print("Shape:", df.shape)
print("Fare statistics:\n", df['fare'].describe().round(3))

# --- Step 2: Calculate Q1, Q3, IQR, and bounds ---
Q1 = df['fare'].quantile(0.25)
Q3 = df['fare'].quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

print("\n--- Outlier Detection Metrics ---")
print(f"Q1 (25th percentile): {Q1:.4f}")
print(f"Q3 (75th percentile): {Q3:.4f}")
print(f"IQR: {IQR:.4f}")
print(f"Lower Bound (1.5*IQR rule): {lower_bound:.4f}")
print(f"Upper Bound (1.5*IQR rule): {upper_bound:.4f}")

# --- Step 3: Count outliers ---
outlier_mask = (df['fare'] < lower_bound) | (df['fare'] > upper_bound)
outlier_count = outlier_mask.sum()
print("\n--- Outlier Count ---")
print(f"Number of values outside bounds: {outlier_count}")

# --- Step 4: Cap the outliers and store in a new column ---
df['fare_capped'] = df['fare'].clip(lower=lower_bound, upper=upper_bound)

print("\n--- Max Fare Comparison ---")
print(f"Maximum fare before capping: {df['fare'].max():.4f}")
print(f"Maximum fare after capping: {df['fare_capped'].max():.4f}")

# --- Step 5: Draw side-by-side box plots ---
plt.figure(figsize=(12, 5))

# Box plot for original fare
plt.subplot(1, 2, 1)
sns.boxplot(y=df['fare'])
plt.title('Fare Distribution Before Capping')
plt.ylabel('Fare')

# Box plot for capped fare
plt.subplot(1, 2, 2)
sns.boxplot(y=df['fare_capped'])
plt.title('Fare Distribution After Capping')
plt.ylabel('Fare')

plt.tight_layout()
plt.show()
```

Notes:
The IQR method was used to define the acceptable range, and the outliers were capped (Winsorized) using `.clip()` instead of being removed. Capping ensures that the extreme values are brought back to the boundary limits, preserving the sample size while mitigating the influence of extreme observations. The box plots visually confirm that the upper whisker of the capped data is truncated at the calculated upper bound.

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# --- Step 1: Load and Profile Data ---
try:
    df = sns.load_dataset('titanic')

    df = pd.read_csv('titanic.csv')
```

```python
# --- Step 4: Print Survival Rate per Age Group ---
age_survival_rate = df.groupby('age_group')['survived'].mean().round(3)
print("\n--- Survival Rate by Age Group ---")
print(age_survival_rate)

# --- Step 5: Cross-tabulation of Sex vs Pclass (Mean Survival Rate) ---
# Calculate the mean survival rate in each cell
sex_pclass_survival = pd.crosstab(df['sex'], df['pclass'], values=df['survived'], aggfunc='mean').round(3)
print("\n--- Mean Survival Rate (Sex vs Pclass) ---")
print(sex_pclass_survival)

# --- Step 6: Plot Survival by Pclass split by Sex ---
sns.set_style('whitegrid')
plt.figure(figsize=(10, 6))
# Use barplot to show the mean survival rate (y) grouped by pclass (x) and split by sex (hue)

plt.ylabel('Mean Survival Rate')

plt.tight_layout()
plt.show()
```

Notes:
The survival rate analysis shows that the youngest age group (Child) has the highest survival rate, while the oldest group (Senior) has the lowest. ### Question

Load the `penguins` dataset from seaborn. Report its shape and how many values
are missing in each column, handle the missing values appropriately for each
column's type, encode the categorical columns, and then produce a correlation
heatmap of the numeric measurements. Finish with two sentences on which

### Answer  (143s, 1374 completion tokens, 9.6 tok/s)

Assumptions:
- The dataset is `penguins`, loaded via `sns.load_dataset`.
- Missing numeric values (measurements) are imputed using the median.
- Missing categorical values (`sex`, `island`) are imputed using the mode.
- `sex` is encoded using a binary map (Male=0, Female=1).
- `species` and `island` are encoded using one-hot encoding (`pd.get_dummies`).
- The final interpretation relies on the printed correlation values.

```python
import pandas as pd
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt

# --- Step 1: Load and Profile Dataset ---
try:
    df = sns.load_dataset('penguins')
except Exception:
    df = pd.read_csv('penguins.csv') # Offline fallback

print("--- Initial Data Profile ---")
print("Shape:", df.shape)
print("\nInitial Missing values per column:\n", df.isnull().sum())
print("\nData types:\n", df.dtypes)

# --- Step 2: Handle Missing Values ---
# Impute numeric columns (measurements) with the median
numeric_cols = ['bill_length_mm', 'bill_depth_mm', 'flipper_length_mm', 'body_mass_g']

    median_val = df[col].median()

df = df.drop('sex', axis=1)

# (b) Nominal Encoding: species and island (One-Hot Encoding)
df = pd.get_dummies(df, columns=['species', 'island'], prefix=['species', 'island'], dtype=int)

print("\n--- Encoded Data Head ---")
print(df.head())

# --- Step 4: Correlation Heatmap ---
# Select only numeric columns for correlation calculation
numeric_df = df.select_dtypes(include=np.number)

# Calculate correlation matrix
corr_matrix = numeric_df.corr()

print("\n--- Correlation with Body Mass (Top 5) ---")
# Print the top 5 correlations with body_mass_g to aid interpretation
print(corr_matrix['body_mass_g'].sort_values(ascending=False).head(5).round(3))

sns.heatmap(corr_matrix, annot=True, fmt='.2f', cmap='coolwarm', center=0, square=True)
```

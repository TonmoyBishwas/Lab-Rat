## RQ3 — R · airquality scatter with NA filtering and trend line

<!-- paste R-mode response here -->
Assumptions:
- The dataset is `airquality`, which contains columns `Ozone` (numeric) and `Wind` (numeric).
- The plot type is a scatter plot with a linear regression line.
- NA values in the `Ozone` column must be removed prior to plotting.

```r
library(ggplot2)

# Filter out rows where Ozone is NA using base R subsetting
airquality_clean <- airquality[!is.na(airquality$Ozone), ]

# Create the scatter plot with a linear trend line
ggplot(airquality_clean, aes(x = Wind, y = Ozone)) +
  geom_point(size = 2, color = "darkblue") +
  geom_smooth(method = "lm", se = FALSE, color = "red", linewidth = 0.8) +
  labs(
    title = "Ozone Concentration vs. Wind Speed",
    x = "Wind Speed",
    y = "Ozone Concentration"
  ) +
  theme_minimal()
```

Notes:
The `geom_point()` creates the scatter plot, and `geom_smooth(method = "lm")` overlays the linear trend line. Using `se = FALSE` removes the shaded confidence interval, making the plot cleaner. The base R subsetting `!is.na()` ensures the NA values are handled before ggplot receives the data.

## PQ1 — Python · Triadic palette using colorsys

<!-- paste Python-mode response here -->
Assumptions:
- The base hue $h$ is $0.7$.
- The triadic palette requires three hues: $h$, $h+1/3$, and $h+2/3$.
- The colors are generated using fixed saturation (0.65) and value (0.9) for visibility.
- The plot will be a single row of three subplots.

```python
import numpy
import matplotlib.pyplot
import colorsys
from matplotlib.patches import Rectangle

# 1. Define base hue and calculate triadic hues
h_base = 0.7
hues = [h_base, h_base + 1/3, h_base + 2/3]

# 2. Generate RGB colors for the palette
# Using fixed S=0.65 and V=0.9 for good visibility
colors = [colorsys.hsv_to_rgb([h, 0.65, 0.9]) for h in hues]

# 3. Plotting the swatches
fig, axes = matplotlib.pyplot.subplots(1, 3, figsize=(12, 3))
fig.suptitle("Triadic Color Palette (h=0.7)")

for i, ax in enumerate(axes):
    color = colors[i]
    # Create a square patch for the swatch
    rect = Rectangle((0, 0), 1, 1, color=color, linewidth=0, edgecolor='black')
    ax.add_patch(rect)
    
    # Set limits and remove axes for a clean swatch display
    ax.set_xlim(0, 1)
    ax.set_ylim(0, 1)
    ax.axis('off')

matplotlib.pyplot.tight_layout(rect=[0, 0, 1, 0.95])
matplotlib.pyplot.show()
```

Notes:
The triadic palette is generated by adding $1/3$ and $2/3$ to the base hue $h=0.7$.
The colors are displayed using `matplotlib.patches.Rectangle` within a $1 \times 3$ subplot grid.
If you wanted a different intensity, adjust the Saturation (S) and Value (V) parameters in `colorsys.hsv_to_rgb`.

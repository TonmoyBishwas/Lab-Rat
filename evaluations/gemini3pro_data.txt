solution:
Assumptions:
- The 'tips' dataset contains 'total_bill', 'tip', and 'day' columns.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.preprocessing import MinMaxScaler

# Load the dataset
tips = sns.load_dataset("tips")

# 1. Custom Harmonic Mean function
def harmonic_mean(x):
    """Calculates the Harmonic Mean: n / sum(1/x_i)"""
    # Handle potential zero values to avoid division by zero
    x = x[x != 0]
    if x.empty:
        return np.nan
    return len(x) / x.apply(lambda val: 1/val).sum()

# 2. Grouping and Calculation
grouped_stats = tips.groupby('day')['total_bill'].agg(
    arithmetic_mean='mean',
    harmonic_mean=harmonic_mean
).reset_index()

# 3. Min-Max Normalization for 'tip'
scaler = MinMaxScaler()
tips['tip_normalized'] = scaler.fit_transform(tips[['tip']])

# 4. Setup Subplots
fig, axes = plt.subplots(1, 2, figsize=(16, 6))
plt.subplots_adjust(wspace=0.3)

# --- Left Subplot: Grouped Bar Chart ---
# Plotting AM vs HM for total_bill by day
sns.barplot(
    x='day', 
    y='arithmetic_mean', 
    data=grouped_stats, 
    ax=axes[0], 
    color='skyblue', 
    label='Arithmetic Mean'
)
# Plotting HM on the same axes (using a different color/marker for distinction)
# Since we are using barplot, we plot the HM data manually on top of the AM bars
ax1 = axes[0]
bar_width = 0.35
index = np.arange(len(grouped_stats['day'].unique()))

# Plot AM bars
ax1.bar(index - bar_width/2, grouped_stats['arithmetic_mean'], bar_width, label='Arithmetic Mean')
# Plot HM bars
ax1.bar(index + bar_width/2, grouped_stats['harmonic_mean'], bar_width, label='Harmonic Mean')

ax1.set_title('Mean Comparison of Total Bill by Day')
ax1.set_ylabel('Total Bill Value')
ax1.set_xlabel('Day')
ax1.set_xticks(index)
ax1.set_xticklabels(grouped_stats['day'])
ax1.legend()
ax1.grid(axis='y', linestyle='--', alpha=0.7)


# --- Right Subplot: Scatter Plot with Normalization and Log Scale ---
# Scatter plot of total_bill vs normalized tip
sns.scatterplot(
    x=tips['total_bill'], 
    y=tips['tip_normalized'], 
    data=tips, 
    ax=axes[1], 
    s=100
)

# Apply logarithmic scale to the x-axis (total_bill)
axes[1].set_xscale('log')

axes[1].set_title('Total Bill vs Normalized Tip (Log Scale)')
axes[1].set_xlabel('Total Bill (Log Scale)')
axes[1].set_ylabel('Normalized Tip')
axes[1].grid(True, which="both", ls="--", alpha=0.5)

plt.suptitle('Custom Statistics Visualization', fontsize=16)
plt.show()
```

Notes:
- For the bar chart, if you needed to compare more metrics (e.g., standard deviation), you would use `sns.barplot` with `estimator` or manually plot multiple sets of bars.
- If the data distribution for the right plot is highly skewed, consider using a log scale for the y-axis as well, or using a KDE plot to visualize the distribution of the normalized tip.
